# Explicitly approved examples

No image files or reference directions are marked approved by this collection.

Generic acknowledgements, a prior assistant recommendation, or an uploaded generated image are not sufficient evidence of design approval. The current request reports dissatisfaction and asks for research before redesign.

When Bibek explicitly approves an item, record:
- exact image/reference ID and version;
- date and the approval statement;
- approved lesson and topic/scope;
- public/private publication authorization;
- source, ownership and any reuse limitations.

Approval of a composition lesson does not grant rights to copy a reference creator's face, branding or artwork. Keep private approved images out of this public repository.
