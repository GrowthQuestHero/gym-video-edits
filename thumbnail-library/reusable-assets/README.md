# Shared reusable assets

- `fonts/anton/`: unmodified Anton Regular and its source OFL.
- `fonts/inter/`: unmodified upright Inter variable font and its source OFL.
- `overlays/`: two original generic contrast scrims; use only when a real photograph needs localized text contrast.

These are preparation assets, not finished thumbnails. No fixed font, color palette or layout is mandatory across videos. Read the [asset index](../asset-index.md) before use. Creator references are not stock assets. No personal source photographs are included here.
